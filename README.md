## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/flutter-practicals.git
   cd flutter-practicals
   ```

2. Make sure Flutter is properly installed by running:
   ```bash
   flutter doctor
   ```

3. Open each practical folder and run:
   ```bash
   flutter pub get
   flutter run
   ```
